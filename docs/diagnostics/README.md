# Diagnostics — TEST IMAGES ONLY

Nothing in this directory is a production game asset. None of it is loaded by
the game, listed in `src/art/AssetRegistry.ts`, or shipped in `dist/`.

These images exist so sprite transparency and level composition can be inspected
without a browser, because `npm install` is blocked in this environment. They
are regenerated by `tools/diagnostics.py`.

| Directory | Contents |
| --- | --- |
| `transparency/` | Character contact sheets over white / black / **magenta** / cobblestone, per-pixel alpha maps with enclosed holes in magenta, and 8–16× zooms used to read frame facing |
| `tilesets/` | Each stage tileset at 6× with a tile grid, for judging what architecture art exists |
| `map/` | The composed Valcendre level: full 960×640 render plus a native 480×270 crop per authored area |

The map render draws the same visible layers in the same order as
`src/core/MapLoader.ts`, so repetition, facades and prop grounding can be
judged. It is a static composition check, not a Phaser screenshot: no lighting,
FX, characters or HUD.

```bash
python3 -I tools/diagnostics.py all           # everything
python3 -I tools/diagnostics.py map           # just the level
python3 -I tools/diagnostics.py zoom tempest  # one sheet at 8x over magenta
```
